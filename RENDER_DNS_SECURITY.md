# Render DNS & Security Fix

## Render DNS Configuration (NO IP NEEDED)

Render doesn't use static IP addresses. Instead:

1. **Deploy to Render first**
2. **Get your Render URL**: `your-app-name.onrender.com`
3. **Add custom domain in Render dashboard**
4. **Use CNAME records** (not A records):

```
Type: CNAME
Name: www
Value: your-app-name.onrender.com

Type: CNAME
Name: @
Value: your-app-name.onrender.com
```

## Security Vulnerability Fix
